## Backup & Restore
- `Database::backup()` / `Database::restore()` in `infra/src/db.rs`; CLI commands in `cli/src/commands/backup.rs`.
- SQLite `ATTACH ... READ ONLY` clause was a syntax error (older sqlx/sqlite) — dropped it.

## Metadata Enrichment
- `MetadataEnrichment { genres, runtime, content_rating, overview, cast_list }` in `core/src/metadata.rs`; exported from `core::lib`.
- `MetadataSearcher::fetch_enrichment(&self, tmdb_id: i32, media_type: &MediaType) -> Pin<Box<dyn Future<Output=Result<MetadataEnrichment, MetadataError>> + Send + '_>>`.
- `HttpClient::fetch_tmdb_enrichment` hits `/{movie|tv}/{id}?append_to_response=credits,release_dates`.
  - Genres: names from `genres[]`. Cast: top 5 from `credits.cast[].name`. Rating: US cert from `release_dates.results` (US) or `content_ratings` for TV. Runtime: movie `runtime` / TV weighted mean of episodes (empty runtime → 0, so mean only when all have values).
  - No API key → `Ok(default)` (matches existing search behavior, tested).
- `FileRecord` + migration 004 columns: `genres` (JSON text), `runtime` (int), `content_rating` (text), `overview` (text), `cast_list` (JSON text).
- `infra/src/db.rs`: JSON encode/decode helpers; all INSERT/UPDATE/SELECT updated.
- `app/src/analyzer.rs`: after a TMDb match, calls `fetch_enrichment`; failures are `warn!` + ignored (match stands).
